# EDR-0001 — Playbook Scope

## Status

Accepted

---

## Decision

The Enterprise AI Playbook is the canonical engineering knowledge base for this portfolio.

Implementation examples, reference projects and runnable systems belong in dedicated repositories.

---

## Rationale

Separating canonical knowledge from implementations:

- reduces duplication;
- improves maintainability;
- provides a single source of truth;
- enables multiple specialized repositories to evolve consistently.

---

## Consequences

- Engineering knowledge is centralized.
- Specialized repositories reference the Playbook.
- Changes to architectural guidance occur in one place.
